# Настройка с нуля

Пятнадцать минут. Ничего программировать не надо — только создать бота,
каналы и вставить несколько строк в настройки репозитория.

## 1. Бот

1. В телеграме открыть [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя — любое (например, «Мои новости»), username должен заканчиваться на `bot`.
3. BotFather пришлёт строку вида `8123456789:AAF...` — это `TG_BOT_TOKEN`.
4. Там же: `/setprivacy` → выбрать бота → `Disable` (иначе бот не увидит команды в каналах).

## 2. Три канала

Создать три **приватных** канала: например «Главное», «Город», «Разбор».
В каждом: «Управление каналом» → «Администраторы» → добавить своего бота
с правом публикации сообщений.

Чтобы узнать id канала: переслать любое сообщение из канала боту
[@userinfobot](https://t.me/userinfobot) — он покажет id вида `-1001234567890`.
Это `TG_CHANNEL_A`, `TG_CHANNEL_B`, `TG_CHANNEL_C`.

Свой личный id узнать там же, написав боту `/start` — это `TG_OWNER_ID`
(бот принимает команды только от него).

## 3. База данных

[Neon](https://neon.tech) → Sign up → New project (регион Frankfurt).
На экране после создания скопировать строку `postgresql://...` — это `DATABASE_URL`.

Бесплатного тарифа хватает с запасом: конвейер хранит три недели постов.

## 4. Ключ модели (можно пропустить)

Без ключа всё работает, но заголовки будут браться как есть, а оценка важности —
только по формуле. С ключом появляются человеческие пересказы, разбор спорных
склеек и французский словарь.

- **Anthropic**: [console.anthropic.com](https://console.anthropic.com) → API Keys →
  Create Key. Это `ANTHROPIC_API_KEY`. Расход ограничен `llm.daily_budget_usd`
  в `config.yaml` (по умолчанию 0,60 $ в сутки — этого хватает с запасом).
- **Groq** (бесплатно, качество ниже): [console.groq.com](https://console.groq.com) →
  API Keys. Тогда `GROQ_API_KEY` и переменная `LLM_PROVIDER=groq`.

## 5. Репозиторий и запуск

```bash
cd ~/Desktop/claude-projects/tgnews-bot
gh repo create tgnews-bot --public --source=. --push
```

Публичный репозиторий нужен ради бесплатных минут GitHub Actions: приватному
на расписании «каждые 10 минут» бесплатного лимита не хватит. Секретов в коде нет —
все токены живут в настройках репозитория.

Дальше в репозитории: **Settings → Secrets and variables → Actions → New repository secret**
и добавить по одному:

| Имя | Значение |
|---|---|
| `TG_BOT_TOKEN` | токен из шага 1 |
| `TG_CHANNEL_A` | id канала «Главное» |
| `TG_CHANNEL_B` | id канала «Город» |
| `TG_CHANNEL_C` | id канала «Разбор» |
| `TG_OWNER_ID` | свой личный id |
| `DATABASE_URL` | строка Neon |
| `ANTHROPIC_API_KEY` | ключ модели (если есть) |

Если используется Groq — вместо ключа Anthropic добавить `GROQ_API_KEY`,
а во вкладке **Variables** создать `LLM_PROVIDER` со значением `groq`.

## 6. Первый запуск

Вкладка **Actions → pipeline → Run workflow** → команда `check-sources`.
В логе будет отчёт: сколько источников живо. Дальше ничего запускать не нужно —
расписание включится само, каждые 10 минут.

Первые сутки лучше просто дать поработать: система копит поток, чтобы было из чего
выбирать. Дайджесты начнут выходить по расписанию (08:00 / 14:30 / 20:00 для «Главного»).

## 7. Подстройка под себя

Всё делается командами боту в личке:

| Команда | Что делает |
|---|---|
| `/digest A` | выпустить дайджест прямо сейчас |
| `/focus ЕГЭ французский` | поднять тему в приоритете |
| `/quiet 22:00-08:00` | сдвинуть тихие часы |
| `/exam_mode on` | режим экзаменов: меньше новостей, выше порог |
| `/add https://site.ru/rss C` | добавить свой источник |
| `/mute lenta 48` | заглушить источник на двое суток |
| `/sources` | что живо, какие веса |
| `/stats` | сколько собрано, отсеяно, опубликовано, потрачено |

Под каждым дайджестом — ряд номеров. Нажать номер → 👍 или 👎. Это меняет вес
источника: то, что нравится, начинает попадать чаще, что раздражает — реже.

Если канал молчит несколько дней — скорее всего, порог слишком высокий:
`score.publish_threshold` в `config.yaml`. Если приходит лишнее — поднять на 5–10.
