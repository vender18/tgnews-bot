# ТЗ v2: персональный новостной агрегатор в Telegram (без второго TG-аккаунта)

## 0. Что изменилось относительно v1

Отказ от Telethon и MTProto. Источники берутся напрямую у изданий. Это не компромисс, а улучшение:

- не нужен второй аккаунт, номер и риск блокировки;
- RSS даёт структурированные данные (заголовок, дата, рубрика, ссылка) вместо сырого текста поста;
- нет рекламных вставок, «подписывайтесь» и эмодзи-мусора — чистить почти нечего;
- источники первичные, а не пересказы пересказов;
- нет rate limit и FloodWait.

Остальная архитектура (дедупликация, скоринг, две полосы публикации, тихие часы, обратная связь) переносится из v1 без изменений.

## 1. Слой сбора: четыре способа, по убыванию приоритета

### Способ 1 — RSS (основной, ~80% источников)
`feedparser` + `httpx`. Опрос раз в 10 минут. Поддержка `ETag` и `Last-Modified`, чтобы не качать неизменившееся.

### Способ 2 — Google News RSS (универсальный)
Закрывает всё, у чего нет своего RSS: региональные новости, узкие темы, иностранные издания.

```
https://news.google.com/rss/search?q={ЗАПРОС}&hl=ru&gl=RU&ceid=RU:ru
```

Примеры запросов:
- `Краснодар` — региональная лента без привязки к конкретному изданию
- `Краснодарский+край+происшествия`
- `ЦБ+ключевая+ставка`
- `ЕГЭ+2027`

Для иностранных: `hl=en&gl=US&ceid=US:en`, `hl=fr&gl=FR&ceid=FR:fr`.

Особенности: заголовок содержит название издания после ` - `, его надо отрезать и записать в источник. Ссылки идут через редирект Google — разворачивать при публикации. Опрос раз в 20 минут, не чаще.

### Способ 3 — `t.me/s/<channel>` (для TG-only источников)
Публичная веб-версия канала, доступна без авторизации и без аккаунта. Парсить `div.tgme_widget_message`, брать `data-post`, текст, время из `<time datetime>`.

Работает **только для публичных** каналов. Опрос раз в 5 минут. Использовать точечно, для источников, у которых нет сайта с RSS.

### Способ 4 — HTML-парсинг (последнее средство)
Только если источник действительно нужен и другого пути нет. Каждый такой парсер — отдельный модуль с изолированным падением: сломался селектор — источник помечается неактивным, конвейер продолжает работать.

**Общий контракт:** все четыре способа отдают один объект:

```python
@dataclass
class RawPost:
    source_id: str
    external_id: str      # guid RSS / URL / id поста
    title: str | None
    text: str
    url: str
    published_at: datetime
    section: str | None   # рубрика, если источник её отдаёт
```

## 3. Что переносится из v1 без изменений

Эти разделы работают так же, независимо от того, откуда пришли данные:

- **Дедупликация и кластеризация** (simhash → сущности → LLM-проверка, окно 6 часов). Здесь она даже важнее, чем раньше: одно событие приходит от Интерфакса, ТАСС, РБК и Ленты почти одновременно.
- **Скоринг**: базовая формула + LLM для кластеров с `base >= 45`. Cross-source count остаётся главным сигналом важности.
- **Две полосы**: экстренное (`score >= 85` и минимум 2 независимых источника, лимит 4/сутки для A и 2/сутки для B) и дайджест по расписанию.
- **Тихие часы 23:00–07:30 МСК.**
- **Расписание дайджестов**: A — 08:00 / 14:30 / 20:00, B — 09:00 / 19:30, C — 18:30 (+ французский пост 08:30).
- **Пустой дайджест не публикуется.**
- **Обратная связь 👍/👎**, тюнинг весов источников, диапазон 0.2–1.2.
- **Команды**: `/digest`, `/focus`, `/quiet`, `/exam_mode`, `/sources`, `/add`, `/mute`, `/stats`, `/check_sources`, `/queue`.
- **Недельный обзор** воскресенье 19:00 и **отчёт по фильтрации** воскресенье 21:00.
- **Экономия на LLM**: rule-based отсев до вызовов модели, Haiku для скоринга батчами, Sonnet только для публикуемого.

## 4. Новое в v2

### 4.1. Нормализация вместо чистки
RSS-описания часто обрезаны на 200–300 символов. Для кластеризации этого хватает, для суммаризации иногда нет. Решение: для кластеров, прошедших порог скоринга, дотягивать полный текст статьи по ссылке (`trafilatura` или `readability-lxml`). Не для всего потока — только для того, что реально пойдёт в публикацию. Это 30–40 запросов в сутки, не нагрузка.

### 4.2. Развороты Google News
Ссылки из Google News идут через редирект. Разворачивать `HEAD`-запросом с `follow_redirects=True` перед публикацией, чтобы в канале была прямая ссылка на издание. Кэшировать результат.

### 4.3. Определение издания
У Google News издание в заголовке после последнего ` - `. У обычного RSS — из конфига. Записывать в отдельное поле, потому что в дайджесте показывается именно оно, а не `source_id`.

### 4.4. Дедупликация Google News против прямых RSS
Google News будет отдавать те же материалы, что придут напрямую от РБК или Ведомостей. Правило: при слиянии в кластер прямой RSS-источник считается основным, Google News не увеличивает `source_count`, если издание уже представлено напрямую. Иначе счётчик независимых источников будет врать и всё подряд полезет в экстренное.

### 4.5. Языковая метка
Поле `lang` у каждого источника. В дайджесте канала A иностранные материалы суммаризируются **на русском**, но с пометкой издания. В канале C французские — остаются на французском, это принципиально.

## 5. Порядок реализации

1. **Этап 1.** `/check_sources` и сбор в SQLite. Все источники из каталога, никакой публикации. Дать поработать 2 дня. Посмотреть: сколько постов в сутки, какие источники мёртвые, какие шумят.
2. **Этап 2.** Дедупликация. Проверять на уже собранных данных, глазами: правильно ли схлопывается одно событие из четырёх агентств. Это самая важная для отладки часть, на ней стоит посидеть.
3. **Этап 3.** Скоринг + канал A, только дайджесты. Неделя работы, потом откалибровать пороги по факту.
4. **Этап 4.** Экстренная полоса, лимиты, тихие часы.
5. **Этап 5.** Канал B (с более высоким порогом) и канал C.
6. **Этап 6.** Французская рубрика.
7. **Этап 7.** Обратная связь, команды, отчёты.

После этапа 3 система уже полезна. Не откладывай запуск до полной готовности.

## 6. Критерии приёмки

- [ ] Ни одного Telegram-аккаунта, кроме основного, для работы не требуется
- [ ] `/check_sources` даёт полный отчёт по живости всех источников
- [ ] Одно событие, пришедшее от 4 агентств, публикуется одним постом
- [ ] За сутки в канал A уходит не более 20 материалов
- [ ] Канал B публикует не больше 8 материалов в сутки, все — реально касающиеся Москвы или Краснодара
- [ ] С 23:00 до 07:30 ни одного уведомления
- [ ] Французский пост приходит ежедневно в 08:30 и содержит оригинальный текст, а не перевод
- [ ] Падение любого источника не останавливает конвейер
- [ ] Расход на LLM укладывается в дневной лимит из конфига
